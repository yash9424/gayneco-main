# Gayneco Main - Arizona Pregnancy Support Network

A comprehensive collection of Next.js applications providing pregnancy support services across Arizona.

## 🏥 Projects

| Project | Description | Services |
|---------|-------------|----------|
| **AHCCCSHelp** | AHCCCS pregnancy confirmation & WIC referrals | Free testing, AHCCCS confirmation, ultrasound |
| **First-Trimester** | Early pregnancy support & guidance | First trimester care, prenatal support |
| **FreePregnencyTest** | Free pregnancy testing services | Walk-in testing, consultation |
| **Low-cost-pregnancy** | Affordable pregnancy care options | Budget-friendly services |
| **NeedUltraSound** | Same-day ultrasound services | Ultrasound appointments, imaging |
| **Pregnancy-Test** | Comprehensive pregnancy testing | Testing, counseling, referrals |
| **SameDayUltraSound** | Immediate ultrasound services | Emergency ultrasound, same-day care |
| **Teen-Pregnancy-Support** | Teen pregnancy counseling & support | Teen-focused care, family support |
| **WalkIn-Pregnancy** | Walk-in pregnancy services | No appointment needed |
| **Wic-Pregnancy-help** | WIC program assistance | WIC enrollment, nutrition support |

## 🛠️ Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript
- **Package Manager:** pnpm

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/yash9424/gayneco-main.git
cd gayneco-main

# Install dependencies for all projects
pnpm install

# Run specific project
cd [project-name]
pnpm dev
```

## 📁 Project Structure

```
└── scripts/              # Utility scripts
```

## 🌐 Deployment

Each project can be deployed independently using:

```bash
# Build for production
pnpm build

# Start production server
pnpm start
```
